## 后端插件结构（`packages/todo/tool-todo/`）

packages/todo/tool-todo/src/

├── index.ts       ← 插件入口（apply 函数 + 工具注册）

├── types.ts       ← 类型定义

├── client.ts      ← 给前端用的类型导出（可选）

└── invariant.ts   ← 测试守卫（可忽略）

比前端还简单——没有 tsx，没有 css，没有 store。纯逻辑。

------

## 核心代码解析

*// 声明依赖：我需要 tools 服务*

export const inject = ['tools']

*// 配置 schema*

export interface Config {

  allowParallelInProgress: boolean

}

*// 插件入口*

export function apply(ctx: Context, config: Config): void {

  *// ★ 核心：注册一个工具给 AI 用*

  ctx.tools.register(defineTool({

​    name: 'todo_write',                    *// 工具名（AI 调用时用这个名字）*

​    description: '...',                    *// 告诉 AI 这个工具干什么*

​    parameters: {                          *// 输入参数 schema（AI 传什么进来）*

​      todos: {

​        type: 'array',

​        items: {

​          type: 'object',

​          properties: {

​            content: { type: 'string' },

​            status: { type: 'string', enum: ['pending', 'in_progress', 'completed'] },

​          }

​        }

​      }

​    },

​    execute(args, exec) {                  *// ★ 实际执行逻辑*

​      const todos = toTodoList(args.todos, allowParallel)

​      exec.agent.session.append('todo/write', { todos })  *// 写入会话日志*

​      return Promise.resolve({ todos, counts: { ... } })  *// 返回结果给 AI*

​    },

  }))

}

## 和前端对比

|          | 前端插件（ui-theme）         | 后端插件（tool-todo）                |
| :------- | :--------------------------- | :----------------------------------- |
| 入口     | `export function apply(ctx)` | `export function apply(ctx, config)` |
| 注册什么 | UI 组件到 slot               | 工具到 `ctx.tools`                   |
| 核心 API | `ctx.slots.inject/register`  | `ctx.tools.register`                 |
| 配置     | 无（或简单）                 | `Config` 接口 + schema 验证          |
| 产出     | 用户看到的 UI                | AI 能调用的工具                      |
| 文件     | tsx + css + store + locales  | 纯 ts（逻辑）                        |

------

## 在 cordis.patch.yml 里怎么注册的？

在 `packages/bundle/base/cordis.patch.yml` 里：

\- id: tool-todo

  name: '@deepseek-ai/dsh-tool-todo'

  config:

​    allowParallelInProgress: false

就这一行，插件就加载了，AI 就能用 `todo_write` 工具了。

------

## 总结：后端插件 3 步

1. cordis.patch.yml 加一行（注册 + 配置）
2. 写 apply(ctx, config)（用 ctx.tools.register 注册工具）
3. 写 execute 函数（工具被调用时干什么）

和前端一样简洁——只不过前端注册的是 UI 组件，后端注册的是 AI 工具。
