## 总结一张图

cordis.patch.yml

  │  "加载 @deepseek-ai/dsh-client-ui-theme"

  ▼

Cordis Loader

  │  import 这个包，找到 apply 函数

  │  调用 apply(ctx)  ← ctx 是框架给的

  ▼

apply(ctx) 执行

  ├── ctx.provide('theme', theme)     // 注册服务到全局

  ├── ctx.on('theme/change', sync)    // 监听事件

  └── ctx.slots.register({            // 注册 UI 到指定 slot

​        name: 'settings.general.item', // ← slot 地址，别人声明的

​        locale: 'settings.theme',      // ← 翻译命名空间

​      }, AppearanceRow)               // ← 渲染这个组件

所有东西的来源：

| 东西                               | 从哪来                                   |
| :--------------------------------- | :--------------------------------------- |
| `ctx`                              | Cordis 框架创建，调用 `apply` 时传入     |
| `'settings.general.item'`          | `ui-settings-general` 插件声明的 slot 名 |
| `SETTINGS_NS` (`'settings.theme'`) | 本文件定义的常量，给国际化用             |
| `AppearanceRow`                    | 本包的 `.tsx` 文件里定义的组件           |
| `store`                            | 本包的 `settings-store.ts` 里创建的      |
