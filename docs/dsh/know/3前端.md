| Vue                               | React (TSX)                 |
| :-------------------------------- | :-------------------------- |
| `.vue` 单文件组件                 | `.tsx` 文件                 |
| `<template>` 写 HTML              | 函数 `return` 里直接写 JSX  |
| `<script setup lang="ts">` 写逻辑 | 函数体就是逻辑              |
| `<style scoped>` 写样式           | `.module.css` (CSS Modules) |
| `ref()` / `reactive()`            | `useState()`                |
| `computed()`                      | `useMemo()`                 |
| `watch()` / `onMounted()`         | `useEffect()`               |
| `v-if` / `v-for`                  | JS 三元表达式 / `.map()`    |
| `defineProps()`                   | 函数参数解构                |
| `$emit()`                         | 回调函数 props              |
