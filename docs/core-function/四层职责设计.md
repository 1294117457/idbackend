# 保研系统四层职责链设计

## 一、总览

```
TemplateCategory  →  Template  →  Application  →  ScoreData
（定义业务规则）      （配置计分）    （记录申请）       （流水结果）
                                                        ↓
                                               User.score_info（汇总快照）
```

---

## 二、数据对象设计

### 1. TemplateCategory（分类树）

```sql
CREATE TABLE template_category (
    id            SERIAL PRIMARY KEY,
    name          VARCHAR(100) NOT NULL,    -- 显示名，如"学业加分"
    code          VARCHAR(50)  NOT NULL,    -- 程序引用码，如"ACADEMIC"，全局唯一
    parent_id     INTEGER REFERENCES template_category(id),
    cat_kind      VARCHAR(20)  NOT NULL,    -- USAGE（一级）| RESTRICTION（二级）
    calc_behavior VARCHAR(20)  NOT NULL DEFAULT 'SCORE', -- SCORE（累加封顶）| QUALIFIER（取最新）
    max_score     DECIMAL(5,2),            -- SCORE 类型时的分值上限，null 表示不限
    sort_order    INTEGER      DEFAULT 0,
    is_active     BOOLEAN      DEFAULT TRUE,
    description   VARCHAR(255),
    created_at    TIMESTAMP,
    updated_at    TIMESTAMP
);
```

**初始数据示例：**

```
id | name    | code      | parent_id | cat_kind    | calc_behavior | max_score
 1 | 加分    | SCORE     | null      | USAGE       | SCORE         | null
 2 | 需求    | DEMAND    | null      | USAGE       | QUALIFIER     | null
 3 | 学业加分 | ACADEMIC  | 1        | RESTRICTION | SCORE         | 50.00
 4 | 专长加分 | SPECIALTY | 1        | RESTRICTION | SCORE         | 30.00
 5 | 劳动教育 | LABOR     | 1        | RESTRICTION | SCORE         | 10.00
 6 | 英语水平 | ENGLISH   | 2        | RESTRICTION | QUALIFIER     | null
```

**关键字段说明：**
- `cat_kind`：USAGE 是一级分类（加分/需求），RESTRICTION 是二级叶子分类
- `calc_behavior`：SCORE = 数值累加 + 上限封顶；QUALIFIER = 字符串取最新值
- `max_score`：仅 SCORE 类型有意义，QUALIFIER 类型为 null
- Template 只能绑定 cat_kind = RESTRICTION 的叶子节点

### 2. Template（计分模板）

```sql
CREATE TABLE score_templates (
    id                SERIAL PRIMARY KEY,
    template_name     VARCHAR(100) NOT NULL,
    category_id       INTEGER NOT NULL REFERENCES template_category(id),  -- 只绑叶子节点
    template_type     VARCHAR(20)  NOT NULL,    -- CONDITION | TRANSFORM（计算引擎类型）
    template_max_score DECIMAL(5,2) NOT NULL,   -- 本模板的分值上限（≤ category.max_score）
    input_unit        VARCHAR(50)  DEFAULT '',  -- 用户输入单位，如"学分"、"分"
    description       TEXT,
    review_count      INTEGER      DEFAULT 1,   -- 审核人数
    is_active         BOOLEAN      DEFAULT TRUE,
    created_by        VARCHAR(50),
    created_at        TIMESTAMP,
    updated_at        TIMESTAMP
);

-- 规则表
CREATE TABLE score_template_rules (
    id          SERIAL PRIMARY KEY,
    template_id INTEGER NOT NULL REFERENCES score_templates(id) ON DELETE CASCADE,
    rule_name   VARCHAR(100),
    rule_type   VARCHAR(20) NOT NULL,        -- CONDITION | TRANSFORM
    rule_score  DECIMAL(5,2),               -- CONDITION 命中后的得分；TRANSFORM 时为 null
    priority    INTEGER      DEFAULT 0,     -- 匹配顺序，越小越优先
    description TEXT,
    created_at  TIMESTAMP,
    updated_at  TIMESTAMP
);

-- 属性表
CREATE TABLE rule_attributes (
    id              SERIAL PRIMARY KEY,
    attribute_code  VARCHAR(50)  NOT NULL,
    attribute_type  VARCHAR(20)  NOT NULL,   -- CONDITION | TRANSFORM
    attribute_value TEXT,                    -- 条件值 或 公式字符串（如 "input * 0.5"）
    input_min       DECIMAL(10,4),           -- 数值区间下限
    input_max       DECIMAL(10,4),           -- 数值区间上限
    input_interval  VARCHAR(20),             -- OPEN | CLOSED（区间边界包含方式）
    display_order   INTEGER      DEFAULT 0,
    description     TEXT,
    is_active       BOOLEAN      DEFAULT TRUE,
    created_at      TIMESTAMP,
    updated_at      TIMESTAMP
);

-- 规则-属性关联
CREATE TABLE rule_attribute_mapping (
    id           SERIAL PRIMARY KEY,
    rule_id      INTEGER NOT NULL REFERENCES score_template_rules(id) ON DELETE CASCADE,
    attribute_id INTEGER NOT NULL REFERENCES rule_attributes(id) ON DELETE CASCADE,
    is_required  BOOLEAN DEFAULT TRUE,
    display_order INTEGER DEFAULT 0,
    created_at   TIMESTAMP,
    updated_at   TIMESTAMP
);
```

**CONDITION 模板数据示例（国家级奖项得10分）：**
```
Template(name="竞赛奖项", category_id=3学业加分, type=CONDITION, max_score=10)
  Rule(priority=1, rule_score=10)
    Attribute(value="national_award")
  Rule(priority=2, rule_score=5)
    Attribute(input_min=85, input_max=100)
```

**TRANSFORM 模板数据示例（劳动学分换算，多区间）：**
```
Template(name="劳动学分换算", category_id=5劳动教育, type=TRANSFORM, max_score=10)
  Rule(priority=1, rule_score=null)
    Attribute(input_min=0, input_max=60, value="input * 0.5")
  Rule(priority=2, rule_score=null)
    Attribute(input_min=61, input_max=100, value="30 + (input - 60) * 0.3")
```

### 3. Application（申请记录）

```sql
CREATE TABLE score_applications (
    id               SERIAL PRIMARY KEY,
    user_id          INTEGER NOT NULL REFERENCES users(id),
    template_id      INTEGER NOT NULL REFERENCES score_templates(id),
    category_id      INTEGER NOT NULL REFERENCES template_category(id), -- 冗余存储，便于聚合
    template_name    VARCHAR(100),   -- 快照，防模板改名影响历史记录
    apply_input      DECIMAL(10,4),  -- 用户输入值（学分数、原始分等）
    apply_score      DECIMAL(5,2),   -- 系统计算得出的申请分数
    gain_score       DECIMAL(5,2),   -- 最终通过的分数（所有 proof 通过后累加）
    status           INTEGER  DEFAULT 0,  -- 0=待审核 1=通过 2=驳回 4=撤回
    review_count     INTEGER  DEFAULT 1,
    remark           TEXT,
    created_at       TIMESTAMP,
    updated_at       TIMESTAMP
);

-- 证明材料
CREATE TABLE application_proofs (
    id             SERIAL PRIMARY KEY,
    application_id INTEGER NOT NULL REFERENCES score_applications(id) ON DELETE CASCADE,
    proof_file_id  INTEGER NOT NULL REFERENCES file_metadata(id),
    proof_value    DECIMAL(5,2),   -- 该证明材料对应的分值
    review_count   INTEGER DEFAULT 1,
    approved_count INTEGER DEFAULT 0,
    status         INTEGER DEFAULT 0,
    review_records JSON,
    remark         VARCHAR(500),
    created_at     TIMESTAMP,
    updated_at     TIMESTAMP
);
```

**关键设计：**
- `category_id` 冗余存储（从 template 反查），避免聚合时频繁 JOIN
- `template_name` 快照存储，历史记录不受模板改名影响
- `apply_score` 由计算引擎在提交时自动算出，不由用户填写
- `gain_score` = 所有状态为"通过"的 proof 的 `proof_value` 之和

### 4. ScoreData（流水记录）

```sql
CREATE TABLE score_data (
    id             SERIAL PRIMARY KEY,
    user_id        INTEGER NOT NULL REFERENCES users(id),
    application_id INTEGER REFERENCES score_applications(id),  -- 来源申请
    category_id    INTEGER NOT NULL REFERENCES template_category(id),
    name           VARCHAR(100),    -- 展示名，如"国家级竞赛奖项"
    value          VARCHAR(200),    -- 统一存字符串（数字存 "10.5"，文本存 "580"）
    academic_year  INTEGER NOT NULL,
    recorded_at    TIMESTAMP DEFAULT NOW()
);
```

**calc_behavior 由 category 决定，ScoreData 本身不存类型：**
```
category.calc_behavior = "SCORE"     → 聚合时对 value 求和 + 封顶
category.calc_behavior = "QUALIFIER" → 聚合时取 recorded_at 最新的 value
```

### 5. User（认证 + 学生基础信息 + 汇总快照）

```sql
-- 在现有 users 表基础上新增两个字段
ALTER TABLE users ADD COLUMN score_info JSONB DEFAULT '{}';
ALTER TABLE users ADD COLUMN extra_info JSONB DEFAULT '{}';
```

**score_info 结构约定：**
```json
{
  "academic_year": 2024,
  "calculated_at": "2024-07-03T10:00:00",
  "scores": {
    "ACADEMIC":  { "name": "学业加分", "raw": 52.0, "score": 50.0, "max": 50.0 },
    "SPECIALTY": { "name": "专长加分", "raw": 28.0, "score": 28.0, "max": 30.0 },
    "LABOR":     { "name": "劳动教育", "raw":  8.0, "score":  8.0, "max": 10.0 }
  },
  "qualifiers": {
    "ENGLISH": { "name": "英语水平", "value": "CET6-520", "updated_at": "2024-05-01" }
  },
  "total_score": 86.0
}
```

**extra_info** 用于存放不走申请流程的静态资质信息（由管理员录入）：
```json
{
  "foreign_language_level": "CET6",
  "sport_level": "national",
  "disciplinary_violations": 0
}
```

## 三、核心方法

### Layer 1：TemplateCategory 核心方法

```python
class TemplateCategoryService:

    @staticmethod
    async def get_category_tree(db) -> list:
        """获取完整分类树，用于管理端配置和前端展示可选模板分类"""

    @staticmethod
    async def get_leaf_categories(db, parent_code: str = None) -> list:
        """获取叶子节点（cat_kind=RESTRICTION），用于模板绑定选择"""

    @staticmethod
    async def get_category_by_code(db, code: str) -> TemplateCategory:
        """通过 code 获取分类，用于聚合计算时读取 calc_behavior 和 max_score"""

    @staticmethod
    async def create_category(db, name, code, parent_id, calc_behavior, max_score) -> TemplateCategory:
        """管理端新增分类节点"""

    @staticmethod
    async def update_category(db, category_id, **kwargs) -> TemplateCategory:
        """管理端修改分类配置（max_score 改变后需重算 score_info）"""
```

---

### Layer 2：Template 核心方法

```python
class TemplateService:

    @staticmethod
    async def get_templates_by_category(db, category_id: int) -> list:
        """获取某分类下的所有启用模板，供学生申请时选择"""

    @staticmethod
    async def get_template_with_rules(db, template_id: int) -> ScoreTemplate:
        """加载模板及其完整规则树（template → rules → attributes），供计算引擎使用"""

    @staticmethod
    async def create_template(db, **kwargs) -> ScoreTemplate:
        """管理端创建模板"""

    @staticmethod
    async def preview_score(db, template_id: int, user_input: float) -> float:
        """预览：给定输入值，返回计算结果，不生成申请记录（供前端实时预览）"""
        template = await TemplateService.get_template_with_rules(db, template_id)
        return ScoreCalculationService.calculate(template, user_input)
```

---

### Layer 3：Application 核心方法

```python
class ApplicationService:

    @staticmethod
    async def submit(db, user_id, template_id, user_input, proof_file_ids) -> Application:
        """
        提交申请流程：
        1. 加载 template（含 rules + attributes）
        2. 调用计算引擎得出 apply_score
        3. 创建 Application 记录（快照 template_name、category_id）
        4. 创建 ApplicationProof 记录
        """
        template = await TemplateService.get_template_with_rules(db, template_id)
        apply_score = ScoreCalculationService.calculate(template, user_input)
        # 创建 Application + Proof ...

    @staticmethod
    async def approve_proof(db, proof_id, reviewer_id) -> ApplicationProof:
        """
        审批单条 proof：
        1. 更新 proof.status = 通过
        2. 累加 proof.proof_value 到 application.gain_score
        3. 若所有 proof 均通过，更新 application.status = 通过
        4. 写入 ScoreData 流水记录
        """

    @staticmethod
    async def reject_proof(db, proof_id, reviewer_id, comment) -> ApplicationProof:
        """驳回单条 proof，不影响 application.gain_score"""

    @staticmethod
    async def revoke(db, application_id, user_id) -> Application:
        """学生撤回申请（仅限待审核状态）"""
```

---

### Layer 4：ScoreData 核心方法

```python
class ScoreDataService:

    @staticmethod
    async def record(db, user_id, application_id, category_id, name, value, academic_year):
        """
        写入一条流水记录（在 approve_proof 完成时由 ApplicationService 调用）
        value 统一存字符串格式
        """

    @staticmethod
    async def recalculate_score_info(db, user_id: int, academic_year: int):
        """
        聚合接口（手动触发）：
        1. 查出该用户该学年的所有 ScoreData
        2. 按 category_id 分组
        3. 读取 category.calc_behavior：
           - SCORE：对 value 求和，与 category.max_score 取小
           - QUALIFIER：按 recorded_at 取最新的 value
        4. 计算 total_score（仅 SCORE 类型参与）
        5. 构建 score_info JSON，写入 user.score_info
        """

    @staticmethod
    async def get_score_summary(db, user_id: int) -> dict:
        """直接读取 user.score_info，用于前端展示，不重新计算"""
```

## 四、完整业务流程

```
管理端配置阶段
  1. 配置 TemplateCategory 树（加分→学业加分/专长加分/劳动教育）
  2. 在叶子分类下创建 Template，配置规则和属性

学生申请阶段
  3. 学生选择 Template（前端从 TemplateCategory 获取分类树展示）
  4. 输入数值 → 前端调用 preview_score 实时预览
  5. 确认提交 → ApplicationService.submit()
     └── 计算引擎自动算出 apply_score
     └── 创建 Application + Proof 记录

审批阶段
  6. 审核员逐条审批 Proof → ApplicationService.approve_proof()
     └── gain_score 累加
     └── 全部通过后 → ScoreDataService.record() 写流水

成绩汇总阶段
  7. 管理员触发 ScoreDataService.recalculate_score_info()
     └── 读取所有 ScoreData → 按分类聚合 → 封顶 → 写入 user.score_info
  8. 前端展示：ScoreDataService.get_score_summary() 直接读 score_info
```

## 五、文件职责划分

```
src/
  models/
    template.py           # ScoreTemplate, ScoreTemplateRule, RuleAttribute, RuleAttributeMapping
    application.py        # Application, ApplicationProof
    score_data.py         # ScoreData（新建）
    template_category.py  # TemplateCategory（新建，替代现有 FieldConfig）

  services/
    template_category_service.py  # 分类树 CRUD
    template_service.py           # 模板 CRUD + preview_score
    calculation_service.py        # 计算策略（ITemplateCalculator + 具体策略）
    application_service.py        # 申请流程（submit / approve / reject / revoke）
    score_data_service.py         # 流水记录 + 聚合计算

  app/routes/
    template_category.py  # 分类管理接口（管理端）
    template.py           # 模板管理接口（管理端）
    application.py        # 申请接口（学生端 + 审核端）
    score.py              # 成绩查询 + 触发重算接口
```

## 六、与现有代码的迁移关系

| 现有对象 | 迁移方向 |
|---|---|
| `FieldConfig` + `FieldSubcategory` | 废弃，替换为 `TemplateCategory`（含 parent_id 树） |
| `ScoreTemplate.score_type`（硬编码枚举） | 废弃，改为 `category_id` 外键 |
| `DemandTemplate` | 合并为 `TemplateCategory` 下 cat_kind=USAGE 的"需求"节点 + 对应 Template |
| `User` 中的业务字段（gpa 等） | 保留在 user 表，新增 `score_info` 和 `extra_info` JSON 字段 |
| 现有 `score_applications` | 新增 `category_id` 冗余字段 |
| 无 | 新建 `score_data` 表 |
