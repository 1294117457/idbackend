##  代码结构分析报告

### 一、问题 1：`deps.py` 和 `dependencies.py` 职责混乱

现状：

| 文件              | 现状内容                                   |
| :---------------- | :----------------------------------------- |
| `deps.py`         | 只包含 `ip_rate_limit` 限流依赖            |
| `dependencies.py` | 包含 Storage 初始化和 FileService 依赖注入 |

问题：

- 两个文件命名混乱：`deps.py`（依赖项的缩写）反而只包含一个限流函数
- Storage 生命周期管理（`set_storage`/`get_storage`/`clear_storage`）不应该混在 `dependencies.py` 中
- `get_db` 被同时 import 到两个文件：`deps.py` 定义并导出，`dependencies.py` 重新导入

建议： 统一合并为一个文件，推荐保留 `dependencies.py`，将 `deps.py` 内容合并进去：

*# 统一为 src/app/dependencies.py*

*# - get_db*

*# - ip_rate_limit*

*# - Storage 生命周期管理*

*# - 各类 Service 的依赖注入函数*

### 二、问题 2：各路由分层不规范

现状对比：

| 路由文件              | 符合标准   | 问题                                                         |
| :-------------------- | :--------- | :----------------------------------------------------------- |
| `file.py`             | ✅ 符合     | Route 只接收请求 → 调用 Service → 返回 Response，VO 转换在 schema 层 |
| `template.py`         | ✅ 基本符合 | Route 较干净，VO 转换在 schema 层                            |
| `extra_info_field.py` | ✅ 符合     | Route 较干净                                                 |
| `application.py`      | ❌ 严重问题 | 包含大量业务代码：`format_application()`、`format_operation()`、`get_application_status_text()` 等 |

### 三、标准分层架构

┌─────────────────────────────────────────────────────────────┐

│  Route 层 (routes/)                                         │

│  - 接收 HTTP 请求/响应                                      │

│  - 参数校验（FastAPI 装饰器）                               │

│  - 调用 Service                                             │

│  - 调用 R.success_resp() 包装响应                          │

└─────────────────────────────────────────────────────────────┘

​                            ↓

┌─────────────────────────────────────────────────────────────┐

│  Schema 层 (schemas/)                                       │

│  - Request: 数据接收 + 校验规则 + to_orm/to_conditions()   │

│  - VO: ORM → ViewObject (from_orm_to_vo)                   │

│  - Page: 分页工具 (from_list_to_page)                      │

└─────────────────────────────────────────────────────────────┘

​                            ↓

┌─────────────────────────────────────────────────────────────┐

│  Service 层 (services/)                                     │

│  - 业务逻辑处理                                             │

│  - 数据库操作                                               │

│  - 事务管理                                                 │

│  - 异常抛出 (NotFoundError, BadRequestError 等)            │

└─────────────────────────────────────────────────────────────┘

​                            ↓

┌─────────────────────────────────────────────────────────────┐

│  Model 层 (models/)                                         │

│  - SQLAlchemy ORM 定义                                      │

│  - 数据库表结构                                             │

└─────────────────────────────────────────────────────────────┘
