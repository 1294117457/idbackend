# 文件模块签名模式改造方案（v6.0）

> **版本**：v6.0（MinIO 全签名代理模式）
>
> **相对 v5.2 的核心变化**：
>
> - **下载从"后端中转流"切换为"MinIO 预签名 URL"**：后端不再从 MinIO 拉字节转发给前端，改为返回一个带签名的直链，前端直接 GET MinIO
> - **上传保持原样**：仍走后端中转（MinIO 不支持浏览器直传 PUT，必须后端中转 + 写元数据），不变
> - **预览统一为签名模式**：移除"AVATAR 公开直链"特例，统一走签名（降低桶策略配置复杂度）
> - **后端带宽压力大幅降低**：下载流量不再走应用服务器
> - **前端 `http.ts` 不再需要 blob 透传逻辑**（管理端尤其受益）
>
> **适用**：学生端（`idfrontend`）+ 管理端（`idfrontend-admin`）+ 后端（`idbackend`）

---

## 1. 设计目标

### 1.1 现状问题（中转流模式）

```
浏览器 ──GET /api/file/11/download──> FastAPI ──get_object──> MinIO
                                              <──bytes─────┘
       <──StreamingResponse (bytes)────
```

**问题清单**：

| # | 问题 | 影响 |
|---|---|---|
| 1 | 应用服务器承担全部下载带宽 | 100 用户下载 50MB 文件 → 服务器 5GB 出向流量 |
| 2 | 大文件把后端内存撑爆 | `storage.download(key)` 把整段读进内存 |
| 3 | 不支持断点续传 / Range | 前端 `<a download>` 没法分片 |
| 4 | 不能挂 CDN | 流量必须经过应用服务器 |
| 5 | 前端需要特殊处理 blob 响应 | `responseType: 'blob'` + `<a download>` 流程复杂 |
| 6 | `Content-Disposition` 编码兼容差 | RFC 5987 vs RFC 2616 解析坑 |

### 1.2 改造目标（签名模式）

```
浏览器 ──GET /api/file/11/download-url──> FastAPI
       <──{url: "https://minio/?X-Amz-Signature=..."}──
       
浏览器 ──GET https://minio/?X-Amz-Signature=xxx──> MinIO
       <──bytes (Content-Type: application/pdf)─────
```

**收益清单**：

| # | 收益 | 说明 |
|---|---|---|
| 1 | 后端带宽归零 | 下载流量由 MinIO 直接吐给前端 |
| 2 | 内存压力归零 | 后端不再 `read()` 整个对象 |
| 3 | 原生支持 Range | MinIO 走 S3 `GetObject` 标准协议 |
| 4 | 可挂 CDN | 签名 URL 走 HTTPS，CDN 可以缓存 |
| 5 | 前端逻辑简化 | 不再需要 blob 透传 / `Content-Disposition` 解析 |
| 6 | 浏览器原生下载体验 | `<a download>` 或 `window.open` 直接触发 |

### 1.3 不改造的部分

- **上传（POST /api/file/upload, POST /api/file/avatar）**：MinIO 不支持浏览器 CORS 直传 PUT（除非配 Presigned POST 策略），且后端需要写元数据，所以保持中转流。
- **查询（GET /api/file/{id}, GET /api/file/search）**：本来就是 JSON 返回，不涉及文件传输。
- **更新 / 删除（PUT / DELETE）**：本来就是 JSON，不涉及文件传输。

### 2.2 接口行为对比

#### preview（旧 → 新）

| | 旧版 `/preview` | 新版 `/preview-url` |
|---|---|---|
| **HTTP 行为** | `GET` 返回 JSON | `GET` 返回 JSON |
| **data 字段** | `FileDataVO` | `FileDataVO`（**字段完全相同**） |
| **url 类型** | AVATAR → 公开直链；POLICY/PROOF → presigned URL | **统一**：全部 presigned URL |
| **过期时间** | 60 分钟（POLICY/PROOF） | 60 分钟（**全部**） |

> ✅ **前端改造极小**：`getPreviewUrl(fileId)` 调用路径不变，返回结构不变，只是 url 类型统一。

#### download（旧 → 新）

| | 旧版 `/download` | 新版 `/download-url` |
|---|---|---|
| **HTTP 行为** | `GET` 返回 `StreamingResponse`（二进制） | `GET` 返回 JSON |
| **data 字段** | `<binary>` | `FileDataVO {id, originalName, contentType, url}` |
| **url 类型** | N/A | **presigned URL，带 `Content-Disposition: attachment`** |
| **过期时间** | N/A（一次性会话） | 60 分钟 |
| **前端触发** | `responseType: 'blob'` + `<a download>` | `window.open(url)` 或 `<a href download>` |

> ⚠️ **关键差异**：旧版前端用 `apiClient.get(..., {responseType: 'blob'})`，新版改为 `apiClient.get(...)` 拿 JSON，然后 `window.open(url)`。

#### 3.1.1 `Storage` 基类新增方法

```python
# idbackend/src/infra/storage/base.py
from abc import ABC, abstractmethod
from typing import BinaryIO, Optional


class Storage(ABC):
    """文件存储的统一接口"""

    # ============= 业务操作 =============

    @abstractmethod
    async def upload(self, file_obj: BinaryIO, key: str,
                     content_type: str = "application/octet-stream") -> str: ...

    @abstractmethod
    async def download(self, key: str) -> bytes: ...

    @abstractmethod
    async def delete(self, key: str) -> bool: ...

    @abstractmethod
    def get_access_url(self, key: str, expiry: int = 3600) -> str: ...

    @abstractmethod
    def get_public_url(self, key: str) -> str: ...

    # ============= v6.0 新增 =============

    @abstractmethod
    def get_presigned_upload_url(
        self,
        key: str,
        content_type: str = "application/octet-stream",
        content_length: Optional[int] = None,
        expiry: int = 3600,
    ) -> dict:
        """生成 MinIO 预签名 PUT URL（保留接口，本期不上线）

        返回结构：
            {
                "url": "https://minio/...?X-Amz-Signature=xxx",
                "headers": {"Content-Type": "...", "x-amz-content-sha256": "..."},
                "expires_at": "2026-07-12T19:00:00Z",
            }

        设计目的：未来支持浏览器直传，绕过应用服务器。
        本期改造不启用，签名上传留给 v7.0。
        """
        raise NotImplementedError

    @abstractmethod
    def get_download_url(
        self,
        key: str,
        original_name: Optional[str] = None,
        expiry: int = 3600,
        force_attachment: bool = True,
    ) -> str:
        """生成 MinIO 预签名 GET URL（强制 attachment 头）

        Args:
            key: 对象键名
            original_name: 原始文件名（用于 Content-Disposition）
            expiry: URL 过期秒数（默认 3600 = 1 小时）
            force_attachment: True → 浏览器强制下载而非预览

        Returns:
            预签名 URL（含 response-content-disposition 头参数）
        """
        raise NotImplementedError

    # ============= 生命周期 =============

    @abstractmethod
    def ensure_bucket(self) -> None: ...

    @abstractmethod
    def close(self) -> None: ...
```

#### 3.1.2 MinIO 适配器实现

```python
# idbackend/src/infra/storage/minio_adapter.py（新增方法）

class MinIOAdapter(Storage):
    # ... 已有 __init__ / upload / download / delete 不变 ...

    def get_presigned_upload_url(
        self,
        key: str,
        content_type: str = "application/octet-stream",
        content_length: Optional[int] = None,
        expiry: int = 3600,
    ) -> dict:
        """生成 MinIO 预签名 PUT URL

        注意：本接口预留，v6.0 不启用，调用方应保持 None / 报错路径。
        """
        params = {
            "Bucket": self._bucket,
            "Key": key,
        }
        url = self._client.generate_presigned_url(
            ClientMethod="put_object",
            Params=params,
            ExpiresIn=expiry,
        )
        # 注：浏览器 PUT 时可能需要再加一些 headers，
        # 但因 CORS 复杂性本期不启用，留作 v7.0 实现。
        return {
            "url": url,
            "headers": {"Content-Type": content_type},
            "expires_at": (
                datetime.utcnow() + timedelta(seconds=expiry)
            ).isoformat() + "Z",
        }

    def get_download_url(
        self,
        key: str,
        original_name: Optional[str] = None,
        expiry: int = 3600,
        force_attachment: bool = True,
    ) -> str:
        """生成带 Content-Disposition: attachment 的预签名 GET URL"""
        params = {
            "Bucket": self._bucket,
            "Key": key,
        }
        if force_attachment and original_name:
            encoded = quote(original_name, safe='')
            params["ResponseContentDisposition"] = (
                f"attachment; filename*=UTF-8''{encoded}"
            )
        elif force_attachment:
            params["ResponseContentDisposition"] = "attachment"
        return self._client.generate_presigned_url(
            ClientMethod="get_object",
            Params=params,
            ExpiresIn=expiry,
        )

    # ... get_access_url / get_public_url / ensure_bucket / close 保持不变 ...
```

```python
async def get_preview_data(
    self,
    file_id: int,
    expiry_minutes: int = 60,

    """返回 (meta, url)——统一签名 URL（v6.0 移除 AVATAR 公开直链特例）
```

```python
    file_id: int,
    expiry_minutes: int = 60,
```

```python
# idbackend/src/app/routes/file.py
"""文件路由（v6.0 全签名模式）

设计原则（docs/file/分层设计.md §1 + docs/file/签名模式改造方案.md）：
- 上传仍走中转流（multipart/form-data → MinIO put_object）
- 预览/下载走签名 URL（返回 JSON，前端用 window.open 触发）
- 路由层只做参数收集 + service 调用 + 序列化
"""
from typing import Annotated
from urllib.parse import quote

from fastapi import (
    APIRouter, Body, Depends, File, Query, UploadFile, HTTPException, status,
)

from src.app.dependencies import get_file_service
from src.app import response as R
from src.app.schemas import (
    FileUploadRequest,
    FileAvatarUploadRequest,
    FileUpdateRequest,
    FileQueryRequest,
    FileVO,
    FileDataVO,
)
from src.services.file_service import FileService

router = APIRouter(prefix="/api/file", tags=["文件"])


# ============ 内部工具 ============

async def _read_and_validate_size(file: UploadFile = File(...)) -> bytes:
    """读取上传字节并校验大小（multipart 协议层硬约束）"""
    from src.infra.config import get_settings

    settings = get_settings()
    content = await file.read()
    if len(content) > settings.MAX_FILE_SIZE:
        raise HTTPException(
            status_code=status.HTTP_413_REQUEST_ENTITY_TOO_LARGE,
            detail=f"文件大小不能超过 {settings.MAX_FILE_SIZE // (1024*1024)}MB",
        )
    return content


# ============ 1. 上传（中转流，逻辑不变）============

@router.post("/upload", status_code=201)
async def upload_file(
    content: bytes = Depends(_read_and_validate_size),
    file: UploadFile = File(..., description="上传文件"),
    fileCategory: str = Query("PROOF"),
    service: FileService = Depends(get_file_service),
):
    """通用文件上传（multipart → MinIO 中转 → DB 写元数据）

    返回的 url 字段是 1 小时有效的下载签名 URL，前端可直接用于预览。
    """
    req = FileUploadRequest(fileCategory=fileCategory, file=file, content=content)
    meta, url = await service.upload_file(req)
    return R.created_resp({
        "fileId": meta.id,
        "originalName": meta.original_name,
        "url": url,
    })


@router.post("/avatar")
async def upload_avatar(
    content: bytes = Depends(_read_and_validate_size),
    file: UploadFile = File(..., description="头像文件"),
    service: FileService = Depends(get_file_service),
):
    """头像上传（multipart → MinIO 中转 → DB 写元数据 → 清理旧头像）

    返回的 url 是 7 天有效的预览签名 URL（不强制下载）。
    """
    req = FileAvatarUploadRequest(
        content=content,
        contentType=file.content_type or "image/jpeg",
    )
    _, url = await service.upload_avatar(req)
    return R.success_resp(url)


# ============ 2. 查询（不变）============

@router.get("/search")
async def search_files(
    req: Annotated[FileQueryRequest, Query()],
    service: FileService = Depends(get_file_service),
):
    """文件分页搜索——Annotated[DTO, Query()] 自动从 query string 解析"""
    page = await service.search_files(req)
    return R.success_resp(page.model_dump())


@router.get("/{file_id}")
async def get_file_info(
    file_id: int,
    service: FileService = Depends(get_file_service),
):
    """单个文件元信息"""
    meta = await service.get_file(file_id)
    return R.success_resp(FileVO.from_orm_obj(meta).model_dump())


# ============ 3. 预览 / 下载（v6.0 全签名模式）============

@router.get("/{file_id}/preview-url")
async def get_preview_url(
    file_id: int,
    expiryMinutes: int = Query(
        60,
        ge=1,
        le=1440,
        description="URL 过期分钟数（默认 60min，最大 24h）",
    ),
    service: FileService = Depends(get_file_service),
):
    """获取文件预览 URL——返回 FileDataVO

    v6.0 行为：
    - 所有 fileCategory 统一走签名 URL（移除 AVATAR 公开直链特例）
    - URL 带 Content-Disposition: inline（浏览器内联预览）
    - 默认 60min 过期
    """
    meta, url = await service.get_preview_data(file_id, expiryMinutes)

@router.get("/{file_id}/download-url")
async def get_download_url(
    file_id: int,
    expiryMinutes: int = Query(
        60,
        ge=1,
        le=1440,
        description="URL 过期分钟数（默认 60min，最大 24h）",

    """获取文件下载 URL——返回 FileDataVO

    v6.0 行为：
    - 后端不再中转字节流，返回签名 URL 让前端直接 GET MinIO
    - URL 带 Content-Disposition: attachment（浏览器强制下载）
    - 默认 60min 过期
    """
    meta, url = await service.get_download_data(file_id, expiryMinutes)
    return R.success_resp(FileDataVO.from_orm_obj(meta, url).model_dump())
```

```nginx
server {
    listen 9000;
    server_name minio.internal;

    # CORS 头（Nginx 层加，比 MinIO 配置更可靠）
    location / {
        if ($request_method = 'OPTIONS') {
            add_header Access-Control-Allow-Origin "$http_origin" always;
            add_header Access-Control-Allow-Methods "GET, PUT, POST, DELETE, HEAD, OPTIONS" always;
            add_header Access-Control-Allow-Headers "*" always;
            add_header Access-Control-Max-Age 3600;
            add_header Content-Type "text/plain; charset=utf-8";
            add_header Content-Length 0;
            return 204;
        }

        proxy_pass http://minio_backend;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_buffering off;
        proxy_request_buffering off;
        proxy_http_version 1.1;

        # 透传 CORS 响应头
        proxy_pass_header Access-Control-Allow-Origin;
        proxy_pass_header Access-Control-Allow-Methods;
        proxy_pass_header Access-Control-Allow-Headers;
        proxy_pass_header Access-Control-Expose-Headers;
```

## 6. 安全与限制

### 6.1 签名有效期

| 场景 | 默认过期 | 可调范围 | 业务说明 |
|---|---|---|---|
| 预览 URL | 60 min | 1~1440 min | 用户主动触发预览，不会长开 |
| 下载 URL | 60 min | 1~1440 min | 下载是即时动作，60min 充裕 |
| 头像 URL（upload 返回） | 7 天 | 配置项 | 头像展示在导航栏等位置，长期有效 |
| 上传返回 URL（通用） | 60 min | 配置项 | 用户上传后短期内可能要预览 |

### 6.2 风险与缓解

| 风险 | 说明 | 缓解 |
|---|---|---|
| 签名 URL 泄露 | 含 `X-Amz-Signature`，记录在浏览器历史/CDN 日志 | 短期过期（≤1h） |
| 前端无法拦截 MinIO 错误 | `window.open` 后看到的是 MinIO XML 错误 | 短期过期 + 引导用户重试 |
| CORS 未配置 | 浏览器拦截跨域请求 | 实施前必须完成 §5.1.1 |
| 离线/弱网 | 签名 URL 还在有效期内，但网络中断 | 用户重新点按钮 → 重新拿签名 URL |
| 防盗链 | MinIO 签名仅认签名，不认 Referer | 业务如有需要可在 MinIO 上挂 Nginx 加 Referer 检查 |

### 6.3 不支持的场景（**需业务方确认**）

| 场景 | 是否支持 | 替代方案 |
|---|---|---|
| PDF / 图片实时水印 | ❌ 不支持（MinIO 不会经过后端） | 保留中转流模式（v5.2 旧 `/download` 接口可临时保留作 fallback） |
| 病毒扫描后再下载 | ❌ 不支持 | 上传时同步扫描，结果写元数据，下载时由前端判断 |
| 动态鉴权（如 PROOF 文件需要申请人本人才能下载） | ⚠️ 部分支持 | 签名生成前在 service 层做业务鉴权即可，签发后失效 |
| 实时转码（如 PDF → 图片预览） | ❌ 不支持 | 仍走中转流 |

> 💡 **建议**：v6.0 全量切换后，旧 `/download` 接口（流式响应）保留 2~3 周作 fallback，给业务方适配时间。3 周后下架。
